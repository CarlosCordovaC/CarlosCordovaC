## 🔭 What I'm currently working on

**BrightcoveProject** — A native iOS app built with SwiftUI that connects 
directly to the Brightcove Video Cloud API. Works like an internal 
TikTok/Reels-style platform for managing and consuming video content securely.

- 🎬 Full-screen video feed with autoplay, pause, mute and progress bar
- 🔐 Secure authentication using Brightcove OAuth + iOS Keychain
- ✏️ Edit, delete and upload videos directly from your phone
- 🔍 Video search powered by the CMS API
- 📱 Built entirely with SwiftUI and async/await
